# SaSarjan Common Core Content

Shared content for the SaSarjan family of websites: the common footer and other copy,
links and assets that should read the same on every site.

Keep each piece of content here once and have the individual websites pull it in, so a change
made here reaches all of them.

## What belongs here

- The shared footer: organisation details, links to sister sites, legal and contact links
- Other text, links or images repeated across the sites
- Nothing site-specific, and no secrets, tokens or `.env` files
